Technologies and architecture

The public website uses HTML, CSS and JavaScript. The application uses React, TypeScript, Vite and Tailwind CSS. React Flow renders diagrams, Yjs supports collaboration, and Tauri provides Windows, macOS and Linux desktop builds.

A separate Laravel API manages accounts, classes and documents. Sanctum provides token authentication, Reverb carries real-time messages, and Filament provides administration. nginx serves the websites and proxies requests to the application server.

Personal data and traffic statistics

The public website does not set advertising cookies. Display preferences are saved locally. Server logs include information such as IP addresses, timestamps, requested resources and browsers for security and traffic measurement. Daily log rotation keeps 14 archived logs in addition to the current log.

Statistics are processed on the server using GoAccess. Reports restricted to administrators do not contain visitor IP addresses or URL parameters. Countries are estimated locally using DB-IP Liteunder the CC BY 4.0 licence. No IP addresses are sent to that provider. These estimates are approximate.

You can use the application without an account to work locally on your device. An account enables online storage and classroom features. The Meriz server processes the data needed for these features; service emails are sent through Brevo. You can delete your account from your profile, subject to the retention rules for educational records and backups.
