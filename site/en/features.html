Features

What Meriz does

A complete modelling workflow, from the first dictionary property to SQL, with tools for collaboration and teaching.

The modelling coreModel from MCD to SQL 6 Teach and learn 6 Work together 3 Across devices, under your control 3
01

Data dictionary

Define each property once with its conceptual type, then place it in at most one entity or relationship. Meriz enforces this Merise uniqueness rule.

02

MCD editor

Create entities, relationships, connections and cardinalities with a mouse or keyboard. Connections stay attached when you move a node.

03

Model validation

Seventeen rules checked continuously: missing identifiers, properties used twice, relationships without connections and invalid cardinalities. Each issue points to the affected element.

04

Logical and physical models

Tables, primary keys, foreign keys and junction tables follow Merise transformation rules. In the physical model, SQL types adapt to MySQL or PostgreSQL and remain editable column by column.

05

SQL script

The CREATE TABLE script includes constraints and can be copied or exported as .sql. Optional DROP TABLE statements can be added before table creation.

06

Laravel and Symfony code

Generate Laravel migrations and Eloquent models, or Doctrine entities and their migration, following each framework’s conventions. These provide the database foundation; your business logic remains yours to write.

01

Classes and invitation codes

Teachers create classes and share a code for students to join. Teacher mode requires a verified school or university email address.

02

Assignments and submissions

An assignment brief, an optional image, a starter model and a reference solution. Students work in the editor and choose when to submit their model.

03

Reviews and comments

A discussion thread for each piece of work, comments pinned to the model, replies and a shared red pencil with temporary or saved drawings.

04

Automatic comparison

Compare a student’s submission with the reference solution: matches, missing elements and differences. The teacher decides the grade.

05

Lessons

Compose lessons from blocks of text, images, videos, audio and examples, then publish them to the class when ready.

06

Live monitoring

When monitoring is enabled, teachers can observe work in progress during a lesson and join a model to edit together.

03
