Mentions légales

Technologies et organisation

La vitrine utilise HTML, CSS et JavaScript. L’application est développée avec React et TypeScript, Vite et Tailwind CSS. React Flow affiche les schémas, Yjs participe à la collaboration, et Tauri permet les versions Windows, macOS et Linux.

Une API Laravel séparée gère les comptes, classes et documents. Sanctum assure l’authentification par jeton, Reverb le transport du temps réel et Filament l’administration. nginx sert les sites et relaie les échanges avec le serveur.

Données personnelles et fréquentation

La vitrine ne dépose pas de cookie publicitaire. Elle mémorise localement les préférences d’affichage. Les journaux du serveur contiennent notamment l’adresse IP, la date, la ressource demandée et le navigateur, pour la sécurité et la mesure de fréquentation. La rotation quotidienne conserve 14 archives de journaux, en plus du journal courant.

Les statistiques sont calculées sur le serveur avec GoAccess. Les rapports réservés à l’administration ne contiennent ni adresse IP de visiteur ni paramètres d’URL. Le pays est estimé localement avec DB-IP Lite, sous licence CC BY 4.0 ; aucune adresse IP n’est envoyée à ce fournisseur. Cette mesure reste approximative.

L’application peut être utilisée sans compte pour travailler sur l’appareil. La création d’un compte permet l’enregistrement en ligne et les fonctions de classe. Les données nécessaires à ces fonctions sont traitées par le serveur Meriz ; les emails de service sont confiés au prestataire d’envoi Brevo. Les données d’un compte peuvent être supprimées depuis le profil, selon les règles de conservation des travaux pédagogiques et des sauvegardes.
